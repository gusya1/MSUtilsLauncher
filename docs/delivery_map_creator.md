# Создание карты доставки

Приложение `delivery_map_creator` создаёт карту доставки на выбранный день: GeoJSON-файл с точками заказов для Yandex Maps. Точка — заказ покупателя, адрес точки — фактический адрес контрагента заказа (геокодируется Яндекс.Геокодером).

## Точка входа

- `views.IndexView` (`site/delivery_map_creator/views.py`) — форма выбора даты доставки; после отправки вызывает `run(date)` и показывает список ошибок и файл для скачивания.
- Контракт: `run(date) -> (error_list, true_filename)` (`site/delivery_map_creator/run/delivery_map_generator.py::run`). GeoJSON сохраняется в `autoclean_default_storage` под именем `DeliveryMap_<ДД.ММ.ГГГГ>.geojson`; при ошибке топ-уровня файл не сохраняется и возвращается пустое имя.

## Обработка

1. Заказы дня — заказы покупателя с `deliveryPlannedMoment` в окне выбранной даты (с 00:00:00 до 00:00:00 следующего дня), запрос к МС с расширением контрагента и проекта (`expand=agent,project`).
2. Blacklist проектов: имена элементов пользовательского справочника МойСклада, название которого задано в `DeliveryMapGeneratorSettings.project_blacklist_dict`. Заказ с проектом из blacklist пропускается без точки на карте.
3. Время доставки — значение дополнительного поля заказа; имя поля — из `MoySkladSettings.delivery_time_attribute_name`.
4. Координаты точки — геокодирование фактического адреса контрагента (`actualAddress`) через Яндекс.Геокодер (ключ — `DeliveryMapGeneratorSettings.yandexmaps_key`).

## Маркеры

- `iconCaption` — «имя заказа (время доставки)»; при отсутствии времени доставки — «имя заказа (None)».
- `description` — фактический адрес контрагента.
- Цвет маркера: `DeliveryMapGeneratorSettings.default_color`; если время доставки не заполнено — `delivery_time_missed_color`.

## Контракт ошибок

- Ошибки отдельных заказов попадают в `error_list`, обработка остальных заказов продолжается, файл сохраняется:
  - «Контрагент [имя]: Адрес не заполнен» — у контрагента нет фактического адреса;
  - «Контрагент [имя]: Адрес не найден на карте» — Яндекс.Геокодер не нашёл адрес;
  - «Ошибка запроса Геокодера: ...» — ошибка запроса к Яндекс.Геокодеру (неверный ключ, превышение лимита или ответ HTTP 400).
- Сбои топ-уровня: файл не сохраняется, возвращается пустое имя файла и одна ошибка в `error_list`:
  - «Ошибка Яндекс Геокодера: ...» — неожиданный статус ответа Яндекс.Геокодера (вне 200/403/429/400) при обработке заказа;
  - «Ошибка выполнения: ...» — в т.ч. «Справочник {имя} не найден!» при отсутствии blacklist-справочника в МС;
  - «Ошибка работы с МойСклад: ...» — сбой запросов к МС (справочник, элементы справочника, заказы).

Запросы к МС идут через локальный клиент `moy_sklad` (`MoySkladClient` + `getters`), токен — из `MoySkladSettings`.
